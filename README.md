# Воронка продаж маркетплейса в Google Таблицах

Демо-проект: Google Таблица на Apps Script, которая сама забирает статистику товаров из API,
строит воронку «показы → карточка → корзина → заказ → выкуп» и отчёт по товарам с сортировкой.

## Что умеет

- **Загрузка через API** с постраничной выдачей, повторами при сбоях (429/5xx) и проверкой ответа:
  если API вернул ошибку или битые данные, старые данные в таблице остаются нетронутыми.
- **Воронка:** ключевые показатели (выручка, заказы, выкупы, средний чек, процент выкупа),
  конверсия каждого этапа, разбивка по категориям, графики воронки и выручки по дням.
- **Отчёт по товарам:** сортировка по выручке, заказам, CTR, конверсиям или проценту выкупа
  из выпадающего списка, цветовая шкала по конверсии и выкупу, строка «Итого».
- **Фильтры:** период и категория на листе «Настройки», пересчёт сразу после изменения.
- **Автообновление** по расписанию (раз в день в выбранный час) и **журнал** всех запусков.

## Структура

```
api/v1/sales-funnel/page-N.json   мок-API: 18 товаров × 60 дней, 250 записей на страницу
apps-script/                      код таблицы
  Config.gs     имена листов, ячейки, этапы, цвета — всё настраиваемое
  Api.gs        загрузка страниц, повторы, проверка ответа
  Funnel.gs     расчёты воронки (чистые функции, проверяются тестами)
  Sheets.gs     листы, оформление, отрисовка воронки и отчёта, журнал
  Menu.gs       меню «Отчёты», пересчёт при правках, расписание
  appsscript.json
tests/funnel.test.js              проверка логики в Node.js
tools/generate_data.py            генератор данных мок-API
```

## Как развернуть

1. **Опубликуйте репозиторий** на GitHub как публичный (`sheets-funnel-demo`) — файлы из `api/`
   станут доступны по адресу
   `https://raw.githubusercontent.com/<логин>/sheets-funnel-demo/main/api/v1/sales-funnel/`.
   Если логин не `Sa1mos`, поправьте `DEFAULT_API_URL` в `Config.gs` или адрес на листе «Настройки».
2. **Создайте Google Таблицу** → «Расширения» → «Apps Script».
3. В редакторе создайте файлы `Config`, `Funnel`, `Api`, `Sheets`, `Menu` (кнопка «+» → «Скрипт»)
   и вставьте в них код из `apps-script/`. Стандартный `Код.gs` удалите.
4. По желанию: «Настройки проекта» → «Показывать файл манифеста» и замените `appsscript.json`.
5. Сохраните, вернитесь в таблицу и обновите страницу — появится меню **«Отчёты»**.
6. **«Отчёты» → «Первичная настройка»** (Google попросит разрешения — это ваш собственный скрипт),
   затем **«Обновить данные из API»**.

## Проверка логики

```bash
node --test tests/funnel.test.js
```

Тесты подменяют сервисы Apps Script заглушками и прогоняют загрузку, повторы, проверку страниц,
расчёты воронки, фильтры и сортировку на данных из `api/`.

## Данные

Данные вымышленные и генерируются детерминированно (`python tools/generate_data.py`).
В них заложены сценарии, которые таблица помогает увидеть: распродажа 11–13 октября
и товар с проблемным выкупом.
